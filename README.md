# miniapp-playground

A collection of packages for [Dozin](https://dozin.ai): each directory is one package that may hold a mini app, the extension it ships, a skill and docs. Dozin 的多应用仓库：每个目录是一个包，可以包含小程序、它带的扩展、技能和文档。

| Package | What it is |
|---|---|
| [`audience-bot/`](audience-bot/) | Audience BOT — Douyin (抖音) live room assistant: live comments and the host's voice go into a Dozin chat, whose AI replies as comments |
